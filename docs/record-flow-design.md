# 試合記録フローの実装契約

更新日：2026-10-26（日本時間）。`js/record-flow.mjs`を実装し、アプリの標準シュート入力へ結合済み。公式の機能と操作順を参照し、独自のUI・コードで作成した。実iPad Safariでの動作は未検証。

## 入力の流れ

- 選手選択→得点またはシュート失敗で下書きを開始。
- STEP 1で任意の攻撃形態・エンプティー・リバウンド・シュート種類・球種と9分割コースを選択。
- シュート失敗は枠外／セーブ／ブロックの結果を先に選ぶ。結果未選択ではコース・省略で先へ進めない。
- 枠外の上・左右、左右ポスト・バーを選んだ場合も位置の段階へ進む。
- コース選択→STEP 2のコート位置をタップして確定。「位置なしで記録」も可能。
- 「戻る」は今回の下書きの値を保持。「記録しない」は確定前取消で、イベントを追加しない。
- 独自の補助操作として「コースなしで次へ」「詳細なしで記録」がある。任意属性の選択値は保持し、未入力のコース・位置は生成しない。
- 相手7mは先に失点／セーブ／枠外の専用結果画面。GKセーブは相手側シュート1件として記録し、自チームGKへ帰属させる。

詳細な公式調査と実画面確認は[記録フローの参照](recording-flow-reference.md)に記録している。戻る・確定失敗時の再試行等は独自版の実装契約であり、原サービスの内部挙動と同一とは断定しない。

## データと時計

下書きの開始時にevent ID・攻撃側チーム・選手・GK・ピリオド・試合時刻を固定する。15秒以内の選手選択時計を利用する既存の記録規則は開始前に適用し、詳細入力の途中では時刻を取り直さない。通常時計と動画からの時計のどちらも、開始時の値を使う。

下書きを`match.events`へ仮追加しない。位置確定・位置省略・詳細省略の確定処理で初めて1イベントを追加する。得点と相手GK失点を別イベントにはしない。新しいシュートでは任意属性・コース・位置を初期化し、前のシュートの詳細を持ち越さない。

## 公開API

| 関数 | 契約 |
|---|---|
| `createRecordFlowDraft(event)` | 固定済みID・チーム・時刻を持つshotイベントから下書きを作る。任意詳細は初期化する。 |
| `answerRecordFlow(draft, patch)` | 許可した詳細だけを不変更新する。ID・時刻・チーム・選手等の固定値変更を拒否する。 |
| `missDirectionAnswer(direction)` | 枠外方向からmiss/postの結果と方向を決める。 |
| `prepareRecordFlowEvent(draft, options)` | 未選択結果を拒否し、位置・コース省略とemptyNetのGK除外を反映したイベントを返す。 |
| `isRecordPositionTap(start,end,threshold)` | ポインタIDと移動距離からタップを判定する。 |
| `mountRecordFlow(dialog,{event,labels,onCommit,onCancel,allowResults})` | 1つのモーダル入力を管理し、cleanupを返す。保存はonCommitが担当する。 |

## 確定・取消・再試行

- 確定中は操作をロックし、連続タップ・二重送信を防ぐ。
- 保存失敗時は同じ内容・IDで再試行できる。新しいイベントIDを作り直さない。
- 保存済みの同じイベントを再追加しない確認は、アプリ側の確定処理でも行う。
- 確定前取消ではイベント件数・得点・GK集計が増えない。保存後の取消は既存の「取り消し」で行う。
- コートのドラッグはタップとして記録しない。キーボードの矢印で位置を選び、Enter/Spaceでも確定できる。
- 画面破棄時はリスナーと表示を片付け、フォーカスを戻す。保存中の取消は受け付けない。

## 実際に確認した結果

PCブラウザで以下を確認した。

- ゴール→コース→位置省略で得点が1増える。
- 確定前取消では得点が増えず、保存後の取り消しで元へ戻る。
- 次のシュートの任意属性は初期化され、戻る操作では現在の下書きの値が保持される。
- 自チームGK #3のセーブは得点を変えず、GKセーブが1増える。
- 1180×820と768×1024で段階画面が収まり、ドラッグ無視・二重送信防止・保存再試行を確認。

全体のNodeテストは直近の実行で78件成功。その後の追加テストを含む最終件数は、再実行した結果を実装状況へ記録する。この文書では再実行前の件数を更新済みとして扱わない。

iPad Safariの実タッチ・ソフトキーボード・画面回転・実試合での記録速度は未検証。PCのiPad相当寸法での検証と区別する。
