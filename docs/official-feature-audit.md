## ユーザー提供分析から補足・訂正すべき点

1. 原サービスは「完全なオフライン起動」を説明していない。起動後の通信断対応を説明している。
2. 全95FAQ、前後半別動画、作戦保存、選手個人の閲覧専用共有、両チーム並列、公式記録などを公式本文で確認できた。
3. 6-0/5-1、クロスなどの戦術タグ分析、出場時間、選手組合せ、AIコメント、映像認識、詳細ロール権限は、取得資料では既存機能として確認できない。独自版の追加候補であり同等性必須機能と混同しない。
4. バックエンドのSupabase/Firebase、IndexedDB/Dexie、同期方式、暗号化・認証強度は資料だけでは断定できない。
5. 公式規約には一般的なアカウント条項がある一方、ガイドのコード共有はログイン不要と説明される。独自実装要件は実際の機能説明を優先し、規約の雛形を技術仕様と解釈しない。
6. 開発者や運営者が閲覧しないというポリシーは、技術的にアクセス不可能という監査証明ではない。

## 実機・公開画面で追加確認が必要な事項

- シュート種類とミス種類の完全な選択肢、7mミスの結果区分。
- 得点効率の厳密な分母、スコア手動補正が統計へどう反映されるか。
- 延長・7m戦、前後半またぎ退場、同時退場、失格の処理。
- 動画アンカーの優先順位と停止区間の補間、同時刻複数イベント。
- Excel形式と実際の書出項目、バックアップスキーマ。
- 作戦盤動画のコンテナ・コーデック、最大録画時間、画面サイズ。
- 同時編集の競合処理、再送重複排除、削除伝播。
- iPadの実機Safari・ホーム画面PWAでの保存・復元・音・動画出力・共有。

## 同等性の判定

上表の各IDに「未着手／実装済未検証／自動検証済／iPad実機検証済」を付ける。機能名だけ画面にある状態は実装済としない。クラウド共有、閲覧リンク、Excel、動画録画出力を代替ボタンやダミー状態で完成扱いしない。

## 公開画面の実見（2026-10-25追記）

新しい使い捨てEdge Chromiumコンテキスト、1180×820・タッチ対応の画面条件で、公式トップ・ガイド・架空サンプル試合を表示した。初回の利用確認案内を閉じ、匿名計測は拒否した。得点・時計開始・編集・共有・削除など、試合データを変更する操作は実行していない。既存利用者のブラウザ／保存データへアクセスしていない。

実際の画面で確認した事項：

- 青系のヘッダー、ホーム／試合／作戦盤／メニューの下部固定ナビゲーション。
- ホームに新規試合、コード入力、3段階導入案内、過去試合、作戦盤、名簿、備品への導線。
- 架空サンプルは試合結果タブで開き、11対5・前後半内訳・退場区間・両チーム比較・得点時系列が表示された。
- サンプル記録タブは両チーム方式で、横長表示では左右のチームパネルが並ぶ。選手・名簿・GK・制裁等のボタンとログをDOM上で確認した。
- 上部の大きい得点・時計、記録／動画メモ／スタッツの3タブ、広い表示・操作音切替が存在する。
- サンプルログではシュート種類（サイド・ミドル・カットイン・ノーマーク）とスカシ等の追加属性が確認できた。選択肢の完全列挙は依然未確認。

ここで確認したのは「画面が表示される」「対象項目がある」ことであり、入力後の正確性、集計精度、同期、動画、作戦録画の動作までを検証したものではない。独自版で画面が再現されたことと機能が同等に動作することも区別する。
