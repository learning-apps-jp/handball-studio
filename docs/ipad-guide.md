# iPadで使うための手順

2026-10-25 開発版。Windows EdgeでのiPad寸法・タッチ条件の検証と、実iPad Safariでの検証は別物です。

## 現在すぐ確認できる方法

PCで `node sync-server.mjs` を実行すると `http://127.0.0.1:4174` で開きます。このURLはそのPCだけのものです。iPadの127.0.0.1からPCへは接続できません。

同じWi-FiでPCのプライベートIPを使う試験は、PowerShellで `$env:HOST='0.0.0.0'; node sync-server.mjs` として起動し、iPadから `http://<PCのLANアドレス>:4174` を開きます。ファイアウォールやルーターの設定を本作業で変更していません。インターネットへのポート公開はしないでください。

LANのHTTPではホーム画面追加・保存の一部は使えても、Service Workerによる完全オフライン起動は使えません。HTTPS公開、または信頼済み証明書のローカルHTTPSが必要です。未承認のドメイン購入・アカウント作成は行っていません。

## 本格利用時の手順

1. 中立ホスト名のHTTPS URLをSafariで開く。
2. 「共有 → ホーム画面に追加」。初回読込み完了を待つ。
3. 架空試合で記録・取消・編集・GK交代を確認。
4. アプリを閉じ、機内モードで再起動し、記録が残ることを確認。
5. バックアップを「ファイル」へ保存し、復元を試す。
6. 作戦盤のドラッグ・録画、生成動画の再生・ファイル共有を確認。
7. YouTubeの前後半動画と時計停止後のアンカーを確認。
8. 練習試合で試験運用し、入力漏れと操作時間を確認。

## 保存と注意点

SafariのWebサイトデータ削除やストレージ整理で保存内容を失うことがあります。ホーム画面アプリとSafariタブで保存領域が異なる場合があるため、使う起動方法を固定し、移行にはバックアップを使ってください。

端末動画ファイルは画面を閉じると再選択が必要です。動画ファイル自体をバックアップに含めません。YouTubeはオンライン専用です。YouTubeの動画再生・実機Safariの録画コーデックは未検証です。

静的ホストで使う場合、試合記録・分析・作戦盤・バックアップは端末内で動きます。8文字コードのリアルタイム共有は別途対応する同期サーバーが必要です。URLだけ公開して同期も動くとは扱いません。

## 公開先の条件

このプロジェクトでは、GitHub個人アカウント名を含むホスト名を最終URLに使わない指定があります。既定の中立候補は `learning-apps-jp.github.io/handball-studio/`。2026-10-25にこのURLで公開する設定へ進めています。公開後はSafariで開いてホーム画面へ追加できます。

Sitesの作成APIが返した予定ホスト名には個人アカウント名が含まれたため、配備していません。Sitesの未公開・非公開プロジェクト識別子だけを `.openai/hosting.json` に保持しています。公開範囲・静的版か同期付きかを決めてから配備します。

### 得点・失点・セーブの入力

自チーム中心の表示では、攻撃の『ゴール』と守備の『失点』『セーブ』を並べて操作できます。今回の選手・GKは詳細画面の上部でも変更できます。GKの変更は記録を確定してから次のプレーへ反映され、キャンセルでは引き継ぎません。保存したプレーはスコアの下に表示され、その場から修正・取り消しできます。表示を変えるときは『両チームを並べる』を使います。
iPadなどのタッチ端末では、記録画面を広い表示で開きます。『標準表示／広い表示』で切り替えた選択は保存されます。広い表示の保存通知は選手・GK・結果と修正／取り消しに絞り、次のプレーのボタンを見やすくしています。
