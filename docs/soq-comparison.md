# SO-Q Stats と Handball Studio の比較

更新：2026-10-26（日本時間）。比較対象はSO-Q Statsの公式資料と、公開済みの [Handball Studio](https://learning-apps-jp.github.io/handball-studio/)（GitHub Pages静的版）。

## 判断の前提

SO-Q Statsの[使い方](https://stats.so-q.jp/guide)と[FAQ](https://stats.so-q.jp/faq)をこの比較のため再取得した。FAQは引き続き全95問、最終更新2026-10-24。既存監査の57項目について、今回再確認した範囲で機能追加・削除に相当する変更は見つからなかった。原サービス内部の実装や、実試合での正確性・安定性を証明する調査ではない。

SO-Q側は公式が説明する仕様と、前回の架空サンプル画面閲覧を根拠とする。Studio側はコードと保存されたPC自動テスト結果を根拠とする。双方を同じiPad実機・同じ試合で比較した操作速度や品質の評価は行っていない。したがって、優劣や完成率は数値化しない。

公開URLは今回の取得でもHTTPS 200を確認。HTTPS公開は済んでいるが、iPad Safariでのホーム画面追加・保存維持・動画出力の実機確認は別に残る。

## 同等性へ向けて比較から決めた5つの作業

1. **個人成績の閲覧先で分析を完結する。** 全／直近5／選択試合、7m、9分割コース、位置・種類別を、他者情報を含めず追加する。公開静的版のままで対応可能。今回モジュール実装、集計6テスト、PCブラウザの画面統合と任意試合選択を確認した。再公開とiPad実機確認を進める。
2. **コメントの追従入力を追加する。** 一覧を下まで読んだ位置から、時刻を保持して停止・入力・再開できるようにする。iPadキーボード表示時に入力欄と送信操作が見えることも確認する。
3. **公開版の8文字コード共有を提供する。** ローカル実装は存在するが、PagesにAPIはない。利用者専用のHTTPS同期先・永続保存・復旧を決めて初めて公開版の機能になる。追加費用や新アカウントを自動で発生させない。
4. **閲覧共有の配布・期限の差を解決する。** 現方式は100KBの長いURLで、原サービスのサーバー型・180日期限と異なる。短い閲覧リンクと期限失効が必要なら3と共通のバックエンドが必要。現方式を継続する場合も、リンクに失効機能がないことを明記する。
5. **iPadの実運用を通しで確認する。** Safariからホーム画面追加→通信断再起動→記録→復帰→実YouTube連動→作戦動画保存／共有→バックアップ復元を確認する。これは未実装と同義ではないが、iPad専用用途で使えると判定するための未達条件である。

全選択肢、得点効率、公式記録用紙への適合、禁止語辞書、細かい動画操作感は引き続き調査・比較が必要。資料で不明なものを勝手に欠如と分類せず、実機未検証を実装済みの保証へ置き換えない。



## 今回の検証追記（2026-10-26）

個人成績レポートをアプリへ結合し、PCブラウザで架空3試合の表示、試合選択モード、1試合の選択解除を確認した。結合段階の全体自動テストは65件成功と報告され、その後に相手名fallbackの回帰テストを1件追加した。個人成績モジュール単独の6件は成功。対戦相手文字列が空の場合は、home/awayとチームIDから相手名を表示し、元の試合データは変更しない。



今回の更新では、初回案内と手動実機チェック、オフライン起動資産の診断、選択チームに限定したホーム一覧/形態率、動画メモ追従、個人成績詳細を追加した。得点補正を含む閲覧リンクで補正値が欠落する不具合と、無人ゴールが個人GK内訳へ入る不具合を修正し、回帰テストを追加した。

## 記録入力の比較で追加確認した差（2026-10-26）

公式サンプルを確定前取消で観察した結果、SO-Q Statsはゴール押下後に、任意の攻撃形態・状況・シュート種類・球種と9コースをまとめたSTEP 1を出し、コース選択後にコート位置を選ぶSTEP 2へ進む。位置タップまたは位置省略が記録の完了操作となる。失敗時は最初に枠外／セーブ／ブロックを選び、GKセーブも同系統の段階を使う。相手7mは先に3択結果を選ぶ。

従来のHandball Studioは即保存中心だったため、集計項目があっても記録の操作順は同等ではなかった。ユーザーの優先指定に従い、標準の入力をこの2段階へ変更し、アプリへ結合した。記録開始時の時計・GK帰属の固定、戻る操作での値保持、確定前取消では記録を増やさないことをPCブラウザで確認した。

これは入力機能と順序の比較であり、公式の意匠・実装コードの複製ではない。サンプルは40件・11対5のままで、公式参考画像は公開しない。詳細は[記録フローの参照](recording-flow-reference.md)へ記録した。
